# Threat Week

A situational cybersecurity simulation from **Launching IT Solutions**.

Students play a new hire at a fictional company through a five-day work week and face 37 situations (phishing, smishing, vishing, deepfakes, evil-twin Wi-Fi, tailgating, ransomware and more), mixed in with legitimate, safe work. Each situation is scored on three thinking skills: Spot, Analyze and Respond.

Modes: Full week, Challenge week (Levels 2–3), Practice one area, and a 12-situation Assessment (pre-test / post-test).

It's a single static page (`index.html`), deployed on Vercel. Progress is stored in the student's browser. At the end, students copy their results code and send it to their instructor.
